# 유튜브 웹드라마/스케치코미디 배우 필모그래피 DB (v2)

## 한 줄 요약

한국 유튜브 웹드라마·스케치코미디 배우·코미디언의 검증 가능한 필모그래피를 구축하는 데이터베이스.

공개된 YouTube 영상 기반으로 출연 이력을 수집·검증하고, 기존 엔터테인먼트 DB가 놓친 유튜브 출신 배우들의 커리어 정보를 구조화한다.

---

# 배경

## 문제의식

한국 유튜브 생태계에서 웹드라마와 스케치코미디는 하나의 독립적인 콘텐츠 장르로 성장했다.

하지만 배우 중심의 필모그래피 데이터베이스는 존재하지 않는다.

현재 배우 정보를 찾는 방식:

- 나무위키
- 검색
- 영상 댓글
- 팬 커뮤니티

등에 의존하고 있으며, 유튜브 출연 이력은 대부분 구조화되어 있지 않다.

---

## 핵심 문제

AI 시대에도 배우 정보를 정확히 찾기 어려운 이유는 AI 성능 문제가 아니다.

원본 데이터가 없다.

예:

> "이 영상에 나온 배우가 누구인가?"
>
> "이 배우가 다른 어떤 유튜브 콘텐츠에 출연했는가?"

라는 질문에 답하려면 검증 가능한 출연 데이터가 필요하다.

현재 YouTube에는 영상은 존재하지만 출연 크레딧 데이터가 없다.

---

# 서비스 정의

## 목표

유튜브 웹드라마·스케치코미디 배우의 필모그래피를 구축한다.

단순한 배우 소개 페이지가 아니라:

```
YouTube 영상
      ↓
출연 사실 데이터
      ↓
배우별 필모그래피
      ↓
검색 서비스
```

구조를 만든다.

---

# 핵심 철학

## 배우 제출 이력보다 공개 증거 우선

배우가 제공하는 이력서는 참고 자료일 뿐, 데이터의 기준이 아니다.

이 서비스의 필모그래피는:

- 공개된 YouTube 영상
- 영상 내 출연 확인
- 공식 채널 정보
- 기타 검증 가능한 자료

를 기반으로 생성한다.

목표는 "주장 가능한 경력"이 아니라 "확인 가능한 출연 이력"이다.

## AI 기반 출연자 후보 추출 (방법 명세)

**현재 방식**: Gemini에 YouTube 영상 링크와 함께 다음과 같은 프롬프트를 전달해 후보를 추출한다.

> "이 영상에 나오는 주연/조연 인물들의 필모그래피와 나무위키 주소를 알려줘"

실제 서비스 단계에서는 프롬프트를 더 정교화할 예정 (역할 구분, 등장 시간대, 신뢰도 근거 등을 함께 요구).

**중요한 전제**: 이 방식은 별도의 얼굴 인식(biometric) API를 쓰는 것은 아니지만, 결과적으로 AI가 영상 속 실존 인물을 식별해내는 행위이기 때문에 개인정보 관점에서 얼굴 인식과 유사한 민감도로 취급한다. 따라서:

- AI가 추출한 결과는 **확정이 아니라 "AI Detected" 상태의 후보**로만 취급한다.
- 이 상태에서는 공개 노출하지 않고, 사람의 교차 검증(나무위키, 공식 채널, 다른 영상과의 대조 등)을 거친 뒤에만 "Human Verified"로 승격한다.
- AI 식별 결과가 틀렸을 경우를 대비해, 이 단계는 처음부터 "미확정 후보"로 문서화해둔다 (→ 아래 정정 절차 참고).

## 데이터 소스

### YouTube

주요 근거 데이터.

- 영상 존재 여부
- 출연 여부
- 채널 정보
- 공개 날짜

---

### 나무위키

주요 데이터 원천이 아니라 탐색 및 보조 자료.

활용:

- 배우 후보 발견
- 인물 관계 확인
- 초기 필모 후보 확보

**라이선스 원칙**: 나무위키는 CC BY-NC-SA 라이선스이므로 텍스트를 그대로 복사하지 않는다. 나무위키에서 얻는 것은 "이 사람이 이 영상에 나왔을 가능성이 있다"는 리드(lead)일 뿐이며, 최종 필모그래피 항목은 반드시 YouTube 영상 등 1차 자료로 재검증한 뒤 우리 표현으로 재작성한다. 나무위키 문장을 문구 단위로 인용하거나 구조를 그대로 가져오지 않는다.

# 검증 시스템

## 출연 검증 상태

```
Unverified
AI Detected
Human Verified
Source Confirmed
```

핵심 원칙:

- 배우 본인의 주장 ≠ 검증 완료
- 공개 영상 확인 = 기본 조건
- 검증 근거를 기록한다

**MVP 범위 참고**: MVP 단계에서는 채널(제작사) 컨택을 하지 않는다. 따라서 "Source Confirmed"는 초기에는 거의 발생하지 않고, 대부분 "Human Verified"에 머무를 것으로 예상한다. 채널 협조를 통한 "Source Confirmed" 확대는 서비스가 나온 이후 별도로 검토한다.

---

## 검증 파이프라인 스케일링

배우가 직접 프로필을 등록하는 방식과 달리, 유튜브 쪽은 영상 수 자체가 훨씬 많아 사람이 100% 수동 검증하는 구조로는 스케일이 안 된다. 자동화 파이프라인 중간에 검증 체크포인트가 반드시 필요하다는 전제로 설계한다.

- **신뢰도 기반 라우팅**: AI 추출 결과의 확신도가 낮은 케이스만 사람 검증 큐로 보내고, 확신도가 높은 케이스(예: 채널에 반복 등장하는 고정 출연진)는 가벼운 검증만 거쳐 승격한다.
- **교차 검증 신호**: 같은 배우가 여러 영상에서 반복적으로 탐지되면 신뢰도가 올라가는 근거로 취급하고, 한 번만 탐지된 케이스는 우선순위를 낮춰 더 꼼꼼히 검증한다.
- **샘플링 감사**: 전수 검증 대신 일정 비율을 무작위 샘플링해 사람이 확인하고, 이를 통해 파이프라인 전체의 정확도를 추정한다.

---

## 정정 절차

"Human Verified"로 표시된 항목이 실제로는 틀렸을 경우를 대비한 절차.

- 배우 본인 또는 제3자가 정정을 요청할 수 있는 채널을 마련한다.
- 정정 요청이 들어오면 해당 항목은 즉시 "Unverified"로 낮추고, 재검증 전까지 비공개 또는 보류 표시한다.
- 정정 처리 이력을 남긴다 (누가, 언제, 무엇을 근거로 수정했는지).

---

## 옵트아웃 절차

- 배우 본인이 자신의 필모그래피 정보를 비공개/삭제해달라고 요청할 수 있는 폼을 서비스에 마련한다.
- 데이터 생성 자체는 여전히 운영자/AI가 수행하지만, 본인이 원치 않을 경우 삭제 요청 채널만큼은 처음부터 열어둔다.
- 옵트아웃 요청 시 해당 배우의 모든 항목을 즉시 비공개 처리하고, 재게시 여부는 본인 동의 없이 임의로 진행하지 않는다.

# GitHub SSOT

## Markdown 기반 관리

데이터 저장소는 JSON DB가 아니라 사람이 편집 가능한 Markdown 기반 SSOT로 운영한다.

목표:

- 사람이 읽을 수 있음
- Git diff 가능
- 수정 기록 추적 가능
- AI 처리 가능
- 정적 페이지 자동 생성 가능

---

- 활동명:

## 필모그래피

### 작품명

- 채널:
- 영상:
- 공개일:
- 출연 확인:

# 운영 방식

- GitHub SSOT
- 정적 페이지 생성
- 서버 비용 최소화
- 초기 운영 비용 0에 가까운 구조

수집과 검증은 운영자가 직접 수행한다. 이 검증 노동력 자체가 초기 진입장벽이자 경쟁력으로 본다 (누구나 쉽게 복제할 수 없는 축적 구조).

---

## 검색/인덱싱 아키텍처

별도의 관계형 DB는 최대한 쓰지 않는 방향으로 설계한다.

- **원칙**: Git(Markdown)이 유일한 SSOT. DB나 검색 인덱스는 저장·관리 대상이 아니라, Git에서 매번 다시 만들어내는 빌드 산출물(캐시)로 취급한다.
- **날짜/정렬**: published_at 같은 정렬용 메타데이터는 영상 파일명에 인코딩해서, 별도 인덱스 없이 파일시스템 레벨에서 처리한다.
- **검색**: RAG 기반 AI 검색을 사용한다. 배포/업데이트 시 "Git → 임베딩 재생성 → 인덱스 파일 교체" 파이프라인으로 처리하고, 사람이 인덱스를 직접 편집하거나 별도로 백업할 일이 없도록 한다.
- **한계 보완**: 임베딩 기반 의미 검색은 "몇 편에 출연했는가", "특정 연도 이후만" 같은 정확한 카운팅·필터링 질의에는 약하다. 이런 질의는 frontmatter 등 구조화된 필드로 먼저 필터링한 뒤, 그 안에서 RAG로 의미 검색하는 하이브리드 방식을 함께 고려한다.

# 수익 모델 방향 (참고용, 확정 아님)

IMDb 자체 광고 수익보다, **IMDbPro** 형태의 B2B 구독 모델이 이 프로젝트와 더 유사한 참고 사례다.

- IMDb: 일반 사용자에게는 무료. 배우/작품 정보 열람에 광고 노출.
- IMDbPro: 캐스팅 디렉터·에이전트·업계 종사자 대상 월/연 구독형 유료 서비스. 배우 연락처·소속사 정보, 진행 중인 프로젝트 상태, 랭킹(STARmeter), 배우 본인의 프로필 직접 관리(사진·데모릴 업로드) 기능 제공.

이 프로젝트에 적용한다면:

- 시청자용 검색은 무료로 유지.
- 업계(소규모 프로덕션, 신인 발굴 담당자 등) 대상으로 필모그래피 데이터 접근(API/대시보드)을 유료화하는 방향을 장기적으로 검토할 수 있다.
- 배우 본인이 옵트아웃뿐 아니라 자기 프로필을 "클레임"해서 직접 관리하게 해주는 기능은 이후 유료 모델과도 자연스럽게 연결될 수 있는 지점이다.

지금 단계에서는 방향성만 남겨두고, 확정은 서비스 검증 이후로 미룬다.
